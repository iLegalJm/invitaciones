# Proyecto: Invitaciones Digitales

Este proyecto genera invitaciones digitales (HTML/CSS/JS) para eventos:
bodas, cumpleaños, XV años, baby showers.

Reglas generales:
- Mobile-first, siempre.
- Cada invitación va en su propia carpeta dentro de /clientes/{nombre}.
- Usar paletas y tipografías consistentes con el tema del evento.
